# Mission Control: HUD v2 rebuild plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Rebuild every view to HUD v2 (Aaron: "build it like this", 2026-11-15), including slim mode, Keep, and the keyboard flow (the held task F8 is folded in here, screen by screen).

**Spec:** `docs/superpowers/specs/2026-11-15-binnacle-hud2-design.md` (the binding authority: grid columns, tiers, rhythm, colours, per-screen contents, keys, commands, the per-file change list). **Mocks:** https://claude.ai/artifact/R4JHk79nyTdVVFszFwfKsb (`Hud2*` row, top of the canvas); sources in the scratchpad `mcstyles/project/Hud2*.dc.html`, generated by `scratchpad/gen-hud2.js` (its column constants are the reference numbers).

## Global Constraints

- The main plan's Global Constraints (`docs/superpowers/plans/2026-11-15-binnacle-mod.md` lines 13–24), `docs/superpowers/notes/2026-11-15-docs-pass.md`, and the features plan's anti-goals (`2026-11-15-binnacle-dx-features.md`) still bind. Hooks observe; nothing added to a conversation except the guide; side effects only on a press or command.
- Layout reads only `e.props.bodyColumns` / `scroll.bodyRows`. Every drawn row ≤ `bodyColumns` on every surface; nothing cut mid-word (`wordFit`), `wrap: 'truncate-end'` as backstop.
- Grid: gutter 0, content from 2, cells at 2/14/26/38/50, metric at 38, time at 50 (wide tier). Tiers and cell counts exactly as the spec's Widths table.
- No Box inside a Button: a row is one Button of padded strings and `Text`; the gutter flag is a sibling `Text` of width 2; cells are fixed-width Boxes.
- Colours only through `style.ts` theme keys. Identity keys. Render writes no state.
- Commands are exactly `/mc`, `/mc 1-5`, `/mc keep <note>`, `/mc export`, `/mc close`, `/mc slim`. `pin` is renamed `keep` everywhere the person sees it; the reducer's internal `pin`/`unpin` events may keep their names.
- Behaviour tests (presses, filters, state writes, exports, needs logic) keep passing; tests that assert the old look are rewritten to assert the new grid (named in each report).
